# 科技大樓站晚餐地圖（eat-what-map）

捷運文湖線科技大樓站（BR08）周邊步行 10 分鐘內、每人 100–300 元的晚餐清單，可以安裝成 PWA。

- 每家都有文字菜單，標註來源與日期；有 2025–2026 年仍營業的紀錄，查不到的會標「待確認」
- 點法只用豬、雞、牛、魚，附保守估計的蛋白質與增肌適合度（A／B／C）
- 篩選：類型、只看營業中、每人預算、搜尋；排序：蛋白質、每百元蛋白質、距離、價格
- 起點可以選科技大樓站、神樂屋或「我的位置」（位置只在瀏覽器裡計算，不會上傳）
- 地圖底圖：內政部國土測繪中心臺灣通用電子地圖（讀不到時改用 Esri）

## 安裝到手機
用手機瀏覽器打開 GitHub Pages 網址：
- iPhone（Safari）：分享 →「加入主畫面」
- Android（Chrome）：選單 →「安裝應用程式」

## 檔案
- `index.html`：整個網頁（資料內嵌）
- `data/shops.json`：店家資料
- `sw.js`：離線快取（頁面先抓網路、地圖圖磚和函式庫走快取）
- `manifest.webmanifest`、`icons/`：PWA 設定

價格和營業時間以店家現場為準。
