# 開發日誌

## 2026-11-04

**做了什麼**
- 收錄 5 家義大利麵店：I'm Pasta 和平店、蘇草 salvia、格芮潘、發現義大利麵、29號館，共 53 家。
- 新增 `tools/gmaps_check.py`：透過本機 Chrome（chrome-local，只綁 127.0.0.1）讀 Google 地圖的營業時間、評分、最新評論時間和外送連結。
- 新增 `tools/menu_fetch.py`：讀 Uber Eats 頁面的 schema.org 菜單（JSON-LD）和 foodpanda 菜單文字。

- 把 Google 地圖／Uber Eats 查證流程整理成 `tools/gm/`：`lib.py`（解析器）、`run.py`（places、menus、report、approve）、`test_parse.py`（14 項測試）、`config.json`、`README.md`；`patches_gm.py` 接進 merge.py。
- 自製 skill `gmaps-menu-verify`，記錄這次的做法和踩坑。

**決策與理由**
- 原本把義大利麵店當成「精緻澱粉」排除，但這不是使用者的條件，所以改為照實評等（B 或 C）後收錄。
- 外送平台價可能比店內貴（I'm Pasta 店內 125 元，foodpanda 185 元）。店內價和外送價分開列；只有外送價的店標示「待確認」。

**踩坑與解法**
- 未登入時，評論不能改成依最新排序，所以「最新評論」只能當成下限。
- foodpanda 會跳 PerimeterX 真人驗證，改以 Uber Eats 為主要菜單來源。
- 菜名模糊比對時，「紅燒莊園牛肉麵」被配到「紅燒牛肉麵」，改成嚴格比對並加了測試。
- Google 地圖「線上點餐」用 Playwright 點擊不一定會開啟，改成讀頁面上的 `searchviewer` 連結，直接開啟。
- 未登入 Google 時是「有限檢視」，相片沒有「菜單」分類。

**下一步**
